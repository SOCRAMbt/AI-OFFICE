Cómo usar el panel de debate

  • Qué muestra: cada HELP_REQUEST dirigido a ["*"] (o a varios agentes) abre un hilo. Debajo se anidan las respuestas: HELP_ACCEPT, HELP_DECLINE, HELP_PARTIAL y HELP_QUESTION, más el STATUS/ANSWER con el que se cierra.
  • Estado: esperando → aceptado / parcial / rechazado → completado. Se completa cuando el hilo recibe una señal de cierre o el TTL del pedido vence.
  • Datos en vivo: corré node dashboard/server.mjs y abrí http://127.0.0.1:7788/debate.html. El server lee .oficina/bus/ en modo sólo lectura.
  • Sin server: arrastrá los JSON de .oficina/bus/peer/ sobre la página, o usá ?demo=1 para ver datos sintéticos.

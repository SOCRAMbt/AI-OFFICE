    send

    • send(channel: string, input: SendInput): Promise<BusMessage>

      Publica un mensaje.

      Si ya existe un mensaje vivo con la misma idempotencyKey en el canal, no se publica un duplicado: se devuelve el existente.

      Atomicidad

      Todo el critical path (chequeo de idempotencia, asignacion de seq y escritura) ocurre bajo un lock de canal. Sin eso:

      • Dos emisores concurrentes con la misma idempotencyKey pasaban los dos el chequeo "existe?" y creaban dos mensajes. La idempotencia era decorativa.
      • Dos emisores concurrentes calculaban el mismo seq y dejaban dos mensajes con el mismo numero, rompiendo el orden del canal.

      Parameters

      • channel: string
      • input: SendInput

      Returns Promise<BusMessage>

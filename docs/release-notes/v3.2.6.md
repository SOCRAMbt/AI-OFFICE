**Cold-start fix: the office auto-deploys an Integrator from a trusted host — nunca más "Solo agentes con canDelegate"**

## El problema

En un root en frío (corrida nueva) ningún agente tiene `canDelegate`. Toda llamada a `oficina_dispatch` era rechazada y las sesiones caían en "fallback" — subagentes genéricos sin motor. Cada sesión nueva, siempre.

## Qué trae

- `src/core/bootstrap.ts` (nuevo): una oficina sin agentes con `canDelegate` se auto-ampara con un **Comandante builtin** (`canDelegate: true`, id = sesión del host) — sólo desde hosts confiables (`build` / `general` / `plan` / `oficina-*`). Sesión no confiable → nada cambia (sigue rechazando, correcto).
- `buildTools` wrapper: ejecuta el bootstrap **antes** de cada tool. Idempotente.
- `tests/coldStart.test.ts` (+3 tests): auto-deploy en `oficina_plan`, auto-deploy en `oficina_dispatch`, trust boundary.
- Suite: 574/574 (v3.2.6).

# @ai-office/host-grok

Grok adapter for AI-OFFICE (OpenAI-compatible, x.ai).

## Install
```bash
npx @ai-office/cli install --platform=grok
```

## Configuration
- Env: `XAI_API_KEY`
- baseURL: https://api.x.ai/v1

## Usage
```bash
ai-office run "prompt"
```

## API
Implements all 14 `HostAdapter` methods.

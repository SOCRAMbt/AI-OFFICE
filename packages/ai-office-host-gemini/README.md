# ai-office-host-gemini

Gemini adapter for AI-OFFICE (Google Generative AI).

## Install
```bash
npx ai-office-cli install --platform=gemini
```

## Configuration
- Env: `GOOGLE_API_KEY`

## Usage
```bash
ai-office run "prompt"
```

## API
Implements all 14 `HostAdapter` methods.
